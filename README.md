# DLFly
> “기록은 성장의 발자국” — 개발자 포트폴리오 겸 기술 블로그

개인 프로젝트로 만든 **Next.js 기반 포트폴리오 겸 블로그 사이트**입니다.<br/>
Notion 기반 CMS와 최신 프론트엔드 스택을 활용하여,<br/>
개발자의 성장을 시각적으로 보여주고 글로 아카이빙할 수 있는 공간을 만들었습니다.

### 🚀 기술 스택
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS, Shadcn UI
- **Data Layer**: Contentlayer, Notion API
- **Deployment**: Vercel, Zapier
- **ETC**: Framer Motion, MDX, TypeScript, SEO 최적화

### 📸 주요 기능
- 개발자 프로젝트 & 블로그 정리
- Notion 기반 기술 블로그 CMS 연동
- 프로젝트 상세 페이지 및 기술 스택 표시
- 반응형 UI
